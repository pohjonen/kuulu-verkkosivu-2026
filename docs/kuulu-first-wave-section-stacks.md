# Kuulu v2: ensimmäisen aallon sivujen section stackit

## Tarkoitus

Tämä dokumentti määrittää ensimmäisen toteutusaallon tärkeimpien sivujen suositellut section stackit.

Ensimmäinen aalto:

1. etusivu
2. videotuotanto
3. koulutus
4. digimarkkinointi
5. case-studies
6. yhteystiedot

Tavoite:

- luoda koko v2-järjestelmän runko
- minimoida shared-riskit
- saada tärkeimmät moduulit suunniteltua heti alussa

---

## Yhteinen perusrytmi

Jokaisen ensimmäisen aallon sivun pitää noudattaa tätä liikettä:

1. huomio
2. kipu / kitka
3. ratkaisun logiikka
4. todisteet
5. seuraava askel

---

## 1. Etusivu (`/v2-etusivu`)

### Tavoite

Master-sivu, joka selittää koko Zero Click -kasvukoneiston.

### Suositeltu stack

1. **Hero Cinematic v2**
   - vahva väite
   - Zero Click -paradigman avaus
   - pää-CTA strategiakartoitukseen / sparraukseen

2. **Problem Grid v2**
   - “tunnistatko nämä” -tyyppinen kitkalista

3. **Audience Split / 95-5 v2**
   - 95 % vs 5 %
   - mitä kummallekin yleisölle pitää tehdä

4. **Service Pillars v2**
   - Brand DNA
   - Sisältökoneisto
   - Liidimoottori

5. **Process Steps v2**
   - miten lähdetään liikkeelle

6. **Stats / Trust Band v2**
   - numerot, referenssit, uskottavuus

7. **Reference Grid v2**
   - tärkeimmät caset

8. **Final CTA v2**
   - strategiakartoitus / sparraus

### Erityishuomio

Etusivulla selitetään koko malli. Tätä ei toisteta muilla sivuilla yhtä laajasti.

---

## 2. Videotuotanto (`/v2-videotuotanto`)

### Tavoite

Näyttää miten Kuulu yhdistää:

- aitouden
- kuvauksen
- hybridi-mallin
- AI-tehostetun skaalan

### Suositeltu stack

1. **Hero Cinematic v2**
   - “Muut myyvät videoita. Me myymme tuloksia.” -henkinen avaus

2. **Problem Grid v2**
   - miksi tavallinen videotuotanto ei tuota tarpeeksi

3. **Video Model Comparison v2**
   - kuvattu
   - hybridi
   - AI-tehostettu

4. **Service Pillars v2**
   - aitous + skaala
   - yksi kuvauspäivä → monta tuotosta

5. **Process Steps v2**
   - tavoite
   - konsepti
   - tuotanto
   - versiointi

6. **Stats / Trust Band v2**
   - katselut, tuotannot, asiakkuudet

7. **Reference Grid v2**
   - videoon liittyvät referenssit

8. **FAQ v2**
   - tuotantomallit, aikataulut, omistajuus, jakelu

9. **Final CTA v2**
   - sparraus / tarjous

### Erityishuomio

Tämä sivu toimii mallisivuna koko captured / hybrid / AI-logiikalle.

---

## 3. Koulutus (`/v2-koulutus`)

### Tavoite

Kytkeä koulutus suoraan markkinoinnin ja tekoälyn murrokseen.

### Suositeltu stack

1. **Hero Cinematic v2**
   - osaamisvaje ja kilpailuetu

2. **Problem Grid v2**
   - miksi nykyinen osaaminen ei riitä

3. **Service Pillars v2**
   - avoimet koulutukset
   - räätälöidyt koulutukset
   - sparraus

4. **Process Steps v2**
   - kartoitus
   - räätälöinti
   - toteutus

5. **Training Agenda v2**
   - aiheet / kategoriat

6. **Stats / Trust Band v2**
   - koulutusten määrä
   - suosittelu
   - palautteet

7. **FAQ v2**
   - hinta, toteutus, aiheet, kenelle

8. **Final CTA v2**
   - tarjouspyyntö

### Erityishuomio

Koulutussivulla kipu tulee ennen agendaa. Ei aloiteta pitkällä kurssilistalla.

---

## 4. Digimarkkinointi (`/v2-digimarkkinointi`)

### Tavoite

Avata miten Kuulu rakentaa kysynnän kotiutusta ja jatkuvaa näkyvyyttä samassa järjestelmässä.

### Suositeltu stack

1. **Hero Cinematic v2**
   - markkinointi joka ei jää yksittäisiksi toimenpiteiksi

2. **Problem Grid v2**
   - hajanaisuus, mittaamisen puute, liidiongelma

3. **Audience Split / 95-5 v2**
   - tunnettuus vs kysynnän kotiutus

4. **Service Pillars v2**
   - Brand DNA
   - Sisältökoneisto
   - Liidimoottori

5. **Process Steps v2**
   - auditointi
   - koneisto
   - optimointi

6. **Reference Grid v2**
   - relevantit markkinointi- ja kasvucaset

7. **FAQ v2**
   - mitä sisältyy, kenelle sopii, miten mitataan

8. **Final CTA v2**
   - sparraus / tarjous

### Erityishuomio

Digimarkkinointi-sivulla pitää näkyä palvelun rooli koko koneistossa, ei vain yksittäisiä palvelupalikoita.

---

## 5. Case Studies (`/v2-case-studies`)

### Tavoite

Tehdä caset helposti löydettäviksi ja nopeasti ymmärrettäviksi.

### Suositeltu stack

1. **Hero Cinematic v2**
   - miksi caseihin kannattaa tutustua

2. **Reference Grid v2**
   - päätason case-kortit

3. **Reference Grid v2** (toinen variaatio tarvittaessa)
   - video
   - koulutus
   - markkinointi
   - AI / hybridi

4. **Final CTA v2**
   - oma tarpeesi / sparraus

### Erityishuomio

Indeksisivu ei saa olla sekava arkisto. Sen pitää ohjata nopeasti oikeisiin caseihin.

---

## 6. Yhteystiedot (`/v2-yhteystiedot`)

### Tavoite

Poistaa viimeinen kitka yhteydenotolta.

### Suositeltu stack

1. **Hero Cinematic v2**
   - selkeä “ota yhteyttä” + matala kynnys

2. **Lead Capture / Form CTA v2**
   - päälomake

3. **Team Grid v2**
   - tärkeimmät yhteyshenkilöt

4. **Contact Info v2**
   - toimistot
   - laskutus

5. **Final CTA v2**
   - varaa sparraus / lähetä viesti

### Erityishuomio

Yhteystietosivu ei saa tuntua hallinnolliselta jäännökseltä, vaan korkean luottamuksen konversiosivulta.

Ensimmäisen aallon section stackit muodostavat koko v2-kokonaisuuden rungon. Kun nämä sivut ja moduulit toimivat:

- suurin osa visuaalisesta kielestä on ratkaistu
