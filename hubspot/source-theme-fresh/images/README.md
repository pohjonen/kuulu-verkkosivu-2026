# Kuulu Theme 2025 - Images

Tämä kansio sisältää Kuulu-teeman kuvat ja grafiikat.

## Kansiorakenne

```
images/
├── favicon.ico              # Sivuston favicon
├── hero-bg.jpg             # Hero-osion taustakuva
├── about-placeholder.jpg   # Tietoja-osion placeholder-kuva
├── icons/                  # Ikonit
│   ├── digital-marketing.svg
│   ├── video-production.svg
│   └── training.svg
├── logos/                  # Logot
│   ├── kuulu-logo.svg
│   └── kuulu-logo-white.svg
└── placeholders/           # Placeholder-kuvat
    ├── team-photo.jpg
    └── office-photo.jpg
```

## Kuvatiedostojen vaatimukset

### Hero-taustakuva
- **Koko:** Vähintään 1920x1080px
- **Muoto:** JPG tai WebP
- **Koko:** Alle 500KB
- **Sisältö:** Kuulu-toimisto, tiimi tai digimarkkinointiin liittyvä kuva

### Ikonit
- **Muoto:** SVG (suositeltu) tai PNG
- **Koko:** 24x24px - 64x64px
- **Tyylit:** Yksinkertaiset, selkeät ikonit Kuulu-brändin mukaisesti

### Logot
- **Muoto:** SVG (suositeltu)
- **Värit:** Kuulu-vihreä (#00A651) ja musta (#1A1A1A)
- **Versiot:** Tavallinen ja valkoinen versio

## Optimoinnit

1. **Kuvien pakkaus:** Käytä WebP-muotoa kun mahdollista
2. **Responsiiviset kuvat:** Tarjoa eri kokoisia kuvia eri laitteille
3. **Lazy loading:** Kaikki kuvat käyttävät lazy loading -ominaisuutta
4. **Alt-tekstit:** Lisää kuvaavat alt-tekstit kaikille kuville
